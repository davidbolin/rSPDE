# Changing the order of the rational approximation

Changing the order of the rational approximation

## Usage

``` r
rational.order(x) <- value
```

## Arguments

- x:

  A `CBrSPDE` or an `rpsde.inla` object

- value:

  The order of rational approximation.

## Value

An object of the same class with the new order of rational
approximation.
